# 加速邻近梯度法 (Accelerated Proximal Gradient, APG)

> **核心定义**：加速邻近梯度法是将 Nesterov 动量加速外推技术与邻近梯度法（PGD）相结合的现代化一阶优化算法。它专用于求解“光滑可微 + 凸不可微”的复合优化问题，是目前非光滑凸优化领域在理论上能达到的一阶算法收敛速度极限（下界）。

---

## 1. 动量加速的直观物理理解

标准的邻近梯度法（PGD）在每一步迭代时，仅仅依赖**当前点**的梯度信息和近端映射。这导致算法在面对高维“狭长峡谷”或病态条件下的目标函数时，容易在峡谷两侧来回震荡，前进缓慢。

APG 引入了 **惯性动量（Inertial Momentum）** 机制：
* **外推步骤 (Extrapolation)**：算法在迈出下一步之前，不仅看当前位置，还会回顾过去两步的运动趋势，沿着上一步的方向“惯性滑行”一段距离。
* **物理直觉**：就像一个带有质量的小球在起伏的表面滚动。由于惯性的存在，小球能够顺畅地冲过平缓的鞍点，并在震荡的方向上相互抵消，从而极大地加快了向全局最优点靠拢的速度。

## ## 2. 算法数学迭代流程

APG（以经典 FISTA 格式为例）通过引入一个辅助状态变量 $y_k$ 来锁死动量信息。其核心迭代步骤如下：

### 算法步骤：
从初始点 $x_0 = x_{-1}$，惯性权重 $t_0 = 1$ 开始，重复以下循环：

1. **动量外推 (Nesterov Extrapolation)**：
   利用前两步的解 $x_k$ 和 $x_{k-1}$ 进行线性组合，计算出外推的中间状态 $y_k$：

   $$y_k = x_k + \left( \frac{t_{k-1} - 1}{t_k} \right) (x_k - x_{k-1})$$

2. **前向梯度下降 (Forward Step)**：
   在 **外推点 $y_k$** 处，对光滑项 $g(x)$ 计算显式梯度下降：

   $$z_k = y_k - \alpha_k \nabla g(y_k)$$

3. **后向邻近修正 (Backward Step)**：
   利用非光滑项 $f(x)$ 的邻近算子对中间状态进行隐式裁剪或投影，得到下一步的真实解 $x_{k+1}$：

   $$x_{k+1} = \text{prox}_{\alpha_k f}(z_k)$$

4. **更新外推权重 (Weight Update)**：
   计算下一步所需的动量加速权重 $t_{k+1}$：

   $$t_{k+1} = \frac{1 + \sqrt{1 + 4t_k^2}}{2}$$

## 3. 收敛速率与量子跃迁

APG 最核心的卖点在于其收敛速度的“质的飞跃”：

* **标准 PGD 速度**： $\Phi(x_k) - \Phi(x^\*) \le \mathcal{O}(1/k)$ 。意味着想要达到 $\epsilon$ 的精度，需要迭代 $\mathcal{O}(1/\epsilon)$ 次。
* **APG (FISTA) 速度**： $\Phi(x_k) - \Phi(x^\*) \le \mathcal{O}(1/k^2)$ 。达到相同的 $\epsilon$ 精度，仅仅需要 $\mathcal{O}(1/\sqrt{\epsilon})$ 次迭代。

### 📊 收敛轨迹对比
在一阶优化算法中，如果没有额外的高阶信息（如 Hessian 矩阵）， $\mathcal{O}(1/k^2)$ 已被证明是黑箱凸优化问题的 **理论绝对上限**（Nesterov 理论下界）。APG 用极低的代数计算成本成功触碰到了这块天花板。

## 4. 算法家族横向对比

| 维度 | 次梯度方法 (Subgradient) | 邻近梯度法 (PGD) | 加速邻近梯度法 (APG/FISTA) |
| :--- | :--- | :--- | :--- |
| **利用结构** | 粗暴整体对待 | 光滑与非光滑解耦 | 解耦 + 历史动量外推 |
| **单调性** | 非单调（需记录历史最优） | 严格单调下降 | **非单调**（由于惯性可能冲过头，但整体收敛极快） |
| **单步计算量** | 极低 | 低（需一次 $\nabla g$ 和一次 $\text{prox}$） | 低（仅比 PGD 多了一次向量减法与加法） |
| **收敛速率** | $\mathcal{O}(1/\sqrt{k})$ | $\mathcal{O}(1/k)$ | $\mathcal{O}(1/k^2)$ （理论极限） |
| **稀疏捕捉** | 极差 | 精确、迅速 | 精确，但在前几步可能由于动量产生轻微震荡 |

## 5. 典型应用场景

* **高性能鲁棒控制系统**：在自动驾驶的长周期预测时域内，多智能体协同优化往往面临巨大的时间压力。APG 可以在极少的迭代次数内，快速给出满足最大加速度硬边界（投影算子）的高精度能耗最优轨迹。
* **图像反卷积与频域重构**：在 2D FFT 图像恢复中，APG 是求解带有全变分（TV 范数）或 $L_1$ 正则化大尺度矩阵的核心加速引擎。
* **大规模协同分布式解耦**：与分布式算法结合，加速各智能体在本地子问题上的收敛速度，大幅削减通信轮数。
